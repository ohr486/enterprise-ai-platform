# enterprise-ai-platform

エンタープライズ向け AI エージェントプラットフォーム（構想段階）。

> **本リポジトリは設計フェーズ以前の初期状態です。**
> 過去に存在した要件定義書・実装プラン・ADR・横断サブシステム（MCP Gateway / Knowledge DB）の設計ドキュメントは、設計を一旦リセットするためにすべて削除されています。

## 構想（最小限の方向性メモ）

エンタープライズ組織向けに、役割固有の AI エージェントを社内ユーザーに提供することを想定。AWS Bedrock と OpenClaw を中核として組み立てる構想がベース。具体的なスコープ・規模・技術選定・フェーズ分割は、設計ドキュメントの再起票時にユーザーと合意のうえ確定する。
